# Villain - Character Sheet

## Appearance

- Lean, imposing, 50s
- Black-and-crimson robes, ornate gauntlets
- Shaved head, piercing grey eyes
- Carries a jeweled staff

## Personality

- Calculating, patient, theatrical
- Believes order is worth any price

## Prompt style

When writing prompts for video generation, prefix with:
`Dark fantasy cinematic still, moody chiaroscuro lighting, `
and reference `assets/characters/villain/reference.png` as the first frame.
